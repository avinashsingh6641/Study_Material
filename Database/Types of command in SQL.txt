| Type    | Full Form                    | Important Commands                    | Purpose      |
| ------- | ---------------------------- | ------------------------------------- | ------------ |
| **DDL** | Data Definition Language     | `CREATE`, `ALTER`, `DROP`, `TRUNCATE` | Structure    |
| **DML** | Data Manipulation Language   | `INSERT`, `UPDATE`, `DELETE`          | Change data  |
| **DQL** | Data Query Language          | `SELECT`                              | Read data    |
| **DCL** | Data Control Language        | `GRANT`, `REVOKE`                     | Permissions  |
| **TCL** | Transaction Control Language | `COMMIT`, `ROLLBACK`, `SAVEPOINT`     | Transactions |
